# 泡芙来信

一封可展开、翻页并播放录音的生日信。包含五页信纸、手工相框照片和生日祝福。

这是 GitHub Pages 发布目录，所有资源均使用相对路径，不需要后端、依赖安装或构建命令。

## 发布设置

在仓库 Settings → Pages 中选择：

- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)

保存后，在 Pages 页面查看实际网站链接。入口为 index.html，.nojekyll 用于直接发布静态文件。

## 更新

修改原项目的 index.html 后，在原项目目录运行 `python scripts/build-pages.py`。
将新生成的 publish 目录内容同步至本仓库。不要只上传 index.html；对应资源也需要上传。
媒体文件名含内容摘要，内容变化会生成新文件名，避免沿用旧缓存。

## 使用

点击橙子展开并开始播放生日录音；音频可暂停、继续和拖动定位。
信纸完全展开后，左半边上一页，右半边下一页。第五页为手绘爱心生日祝福。
在手机上，照片位于信纸下方。系统启用减少动画时，翻页直接切换。

字体许可见 LICENSES.md。照片与录音随此网站一起公开发布。
